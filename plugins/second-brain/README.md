# Second Brain

Deze plugin koppelt Codex/ChatGPT aan de beveiligde Second Brain MCP-server op `https://mcp.roanensven.nl/mcp`.

De plugin biedt persoonlijk geheugen, expliciet geselecteerde Home Assistant-bronnen, bevestigde tv- en media-acties en cameraweergave via MCP Apps. De generieke `home-control`-skill kiest uitsluitend acties en camera's uit de catalogus die de gebruiker zelf heeft ingesteld.

## Koppelen

Installeer **Second Brain** vanuit deze marketplace en kies **Verbinden**. Rond de beveiligde OAuth-koppeling af en gebruik daarna `brain_setup` in de chat om Home Assistant te koppelen en bronnen, camera's en acties te selecteren.

Home Assistant-tokens, MCP-pairing keys, OAuth-sessies en opgeslagen persoonlijke gegevens staan niet in deze repository.
